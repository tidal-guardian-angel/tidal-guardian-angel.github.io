# 多方法计算规则

本文说明网站实际采用的课程规则与公开的实现约定。课程出处只列资料名和页号，不随网站提供原始课程 PDF、PPT 或其中的图像。网站及源码入口仍为品牌组织站点，发布方式仍为 `main` 保存源码、`gh-pages` 保存构建文件。

## 八个入口与路由

首页有八个可展开的抽屉。方法通过同一页面的 `?method=...` 查询参数进入，返回首页可重新选择方法。查询参数只表示方法，不携带出生资料或姓名。

| 方法 | `method` 路由键 | 输入与选星 |
| --- | --- | --- |
| 五生命点取字 | `five` | 五个生命点及昼夜，直接按位置取字。 |
| 命主星法 | `ascendant` | 上升星座的古典本垣守护星。 |
| 月座法 | `moon` | 月座的下一星座之古典本垣守护星。 |
| 角宫法 | `angles` | 四个几何角点的本质尊贵总分最高者。 |
| 第十一宫法 | `eleventh` | 十一宫本垣宫主，或该宫头的本质尊贵最高者。 |
| 姓名计算法 | `name` | 使用者确定的完整字母拼写、数表、后缀及拆分。 |
| 胜利星取字 | `almuten` | 使用者手动选择已按所用版本确认的胜利星。 |
| 日月取字 | `luminary` | 使用者手动选择太阳或月亮。 |

星盘路径采用七颗古典行星：太阳、月亮、水星、金星、火星、木星、土星。各星所在位置与据以选星的点位分别保留，计分结果用于选择行星，取字读取所选行星的实际黄经。

## 五生命点原有规则

五点仍为太阳、月亮、上升、福点和出生前朔望。朔望使用出生时或之前最近一次精确新月或满月时的**月亮**黄经。

- 昼生福点：`(上升＋月亮−太阳) mod 360°`。
- 夜生福点：`(上升＋太阳−月亮) mod 360°`。
- 昼生取字顺序：太阳、月亮、上升、福点、朔望。
- 夜生取字顺序：月亮、太阳、上升、福点、朔望。

计算福点时保留原始度分秒；查字时才向下取累计整数度，不四舍五入。从白羊座0°开始，22个基础希伯来字母按顺序逐度循环，整数行 `d` 对应零基字母索引 `d mod 22`。五个根字母全部保留，包括重复字母，最后添加 `אל / el`。

五点的坐标、查字、昼夜公式及排序保持原规则。固定拼读的显示由下述完整课程表提供，字母名、数值与根字母来源仍可核对。五点法不需要先完成胜利星计分。

出处：原《HGA Lesson 2》第17—19页；当前第二课PPT第19—26、34页。

## 其余星盘路径的构名步骤

每颗选定行星按以下流程单独生成名号：

1. 读取它的实际回归黄道位置，保留原始度分秒。
2. 按页面明确选择的布字起点计算查表行。
3. 由22字母循环表取**一个根字母**。
4. 添加 `אל` 两个后缀字母，按固定表拼读，并将后缀读作 El。

这些单星结果通常为一个根字母加两个后缀字母。星座、度、分、秒不会各自再拆成一个字母。多个并列候选分别构名，不自动拼成一个更长的名字。

### 两种布字起点

页面为六项新增星盘路径提供两种选择，并将选项与实际行号写入结果：

- **从白羊座0°起**：`查表行 = floor(行星累计黄经)`。
- **相对上升**：`查表行 = (floor(行星累计黄经) − floor(上升累计黄经) + 360) mod 360`。

两种方式均沿黄道星座顺序布字。相对上升的当前界面默认选项可见且可修改；它采用先分别取整数行、再相减的口径。

课程例：水星摩羯29°24′09″、上升处女24°35′21″，查 `299−174=125` 行，得 `ע`，加后缀为 `עאל / Eael`。若先对完整度分秒作差，再把124°48′48″向下取整，会查124行；这与本例的整数行算法不同。负差先绕回0—359行，再作22字母循环。

出处：原讲义第10—11页；当前PPT第48、50、56页。原讲义并未为后续每条路线重新固定起点，网站因此将起点作为明确选择记录。

### 命主星与月座

命主星法取上升星座的古典守护星；月座法先沿黄道取月亮所在星座的下一个星座，再取该星座的古典守护星。随后使用所选行星的实际位置完成上述构名步骤。

月座例：月亮在双子座，下一星座为巨蟹座，因此选月亮；换成其他月座，所选行星可能不同。星座顺序循环衔接，双鱼座之后是白羊座。

出处：原讲义第11、13页；当前PPT第50—51页。

### 胜利星与日月

网站不自动计算整盘胜利星，也不自动比较日月强弱。使用者先按自己采用的课堂判断或其他明确版本选星，再在页面手动确认；出生资料模式可以自动取得这颗已选行星的位置。

胜利星允许选择七颗古典行星之一；日月法只允许选择太阳或月亮。网站后续负责起点换算、查字、固定拼读和后缀。课程不同材料的选星示例与计分口径存在差别，因此结果记录手动选星，不把某一例的选择推广为所有星盘的统一规则。

出处：原讲义第12、14页；当前PPT第47—48、52页。

## 四角与十一宫的本质尊贵计分

### 本网站采用的计分表

每个考察位置按以下项目将分数分配给相应行星，同星兼任多项时累加：

| 项目 | 分值 | 采用的表 |
| --- | ---: | --- |
| 入庙 | 5 | 古典七星本垣守护。 |
| 擢升 | 4 | 课件擢升表；处女座水星的擢升分计入。 |
| 三分 | 3 | 多罗修斯三分，按所选口径。 |
| 界 | 2 | 原讲义所列埃及界。 |
| 面 | 1 | 原讲义所列十度区主星。 |

三分默认按昼夜取一颗当令主星加3分，这是当前课件的主练习口径；另一选项为昼主、夜主、参与主星各加3分，结果会明确记录这一不同口径。

界采用半开区间。例如课件白羊座的累计上限为6、12、20、25、30度；依次为木星、金星、水星、火星、土星。到6°00′即进入下一界，不能用另一套同名表替代。尊贵判断保留精确点位，取字的整数行规则另行应用。

出处：原讲义第9页；当前PPT第36—46页。

### 角宫法

当前网站实现四角本质尊贵计分这一分支：考察上升、天底、下降、天顶四个几何角点，逐点分配上述分数，再按七星逐列合计。下降为上升的对点，天底为天顶的对点。最高分行星的实际位置用于取字。

四角是天文轴线；整宫制下，第十宫起点不一定等于天顶。页面因此要求真实上升与天顶位置，不用一个假定的十宫起点代替天顶。网站此分支不比较角宫主星的后天状态，也不计算宫位、值日、值时等整盘附加分。

原讲义还介绍角宫主星状态比较这一分支，当前入口的名称和记录说明采用四角本质尊贵计分。出处：原讲义第15页；当前PPT第53页及演讲备注。

### 第十一宫法与宫制

页面提供两种选星方式：

- 十一宫本垣宫主星：取该宫头所在星座的古典守护星。
- 十一宫宫头尊贵计分：在该宫头精确位置按上述规则分配分数，保留全部最高分行星。

出生资料模式须明确选择 Porphyry、Regiomontanus、Placidus 或 Whole Sign 宫制；宫头随所选宫制计算，并在结果中记录。手动模式直接抄入原星盘的十一宫宫头，使用者应先确认该原盘宫制；网站不会从一个手填宫头反推出宫制。

课程并列例：十一宫头巨蟹23°11′35″，夜生单主口径下，月亮入庙5加面1，共6分；木星擢升4加界2，共6分；火星夜间水象三分3分。因此月亮与木星分别生成名号。首项仅用于初始展示，并不代表自动胜出；可切换候选，保存、打印或复制当前候选记录。

出处：原讲义第16页；当前PPT第54页及演讲备注。

## 姓名计算的明确实现约定

### 输入、加权与后缀

姓名法不使用出生星盘。使用者先按自己采用的课程版本整理完整姓名及字母拼写，再选择拉丁、希伯来或阿拉伯输入体系。网站不自动把中文转成拼音，也不按汉字笔画计算。

当前输入最多40个字母，忽略空白、连字符和撇号；清理后按全串从1连续编号，不在姓名字段之间重置。拉丁输入使用原讲义数表的 English 大数列：A—I为1—9，J为10、K为20，依此至R为90；S为100、T为200，依此至Z为800。它与简单的 A=1 至 Z=26 求和不同。希伯来、阿拉伯输入按各自课件大数表处理。

计算公式为 `T = Σ(字母数值 × 连续序号)`，每个字母的数值、序号、乘积与累计和都会展示。选择 el 后缀时 `S=T−31`，选择 Ayl 时 `S=T−41`。当前实现要求 `0<S<1,000,000`，拆数、映射后再添加先前扣除的同一后缀。

原讲义第4页规定加权、减后缀和拆数的结构，但没有把所有输入整理和通用拆数细则写成唯一算法。本网站将连续编号等约定写入结果，便于复核；这些约定不被表述为唯一古法。

### 自动拆分与人工复核

当前自动拆分约定如下：

1. 不足1000的数按百、十、个位拆分，零项略去；11—19明确拆为10加个位。
2. 达到1000时，先把千位商按上述方式拆分，再记一个1000，最后拆不足1000的余数。
3. 例如 `41854 → 40、1、1000、800、50、4`，与原讲义的明确示例一致。

这些数值不是直接相加还原原数。含1000时，用“1000前各项之和乘1000，再加1000后各项之和”校验；例如 `(40+1)×1000+800+50+4=41854`。不含1000时，直接求和校验。使用者可手动提供拆分序列；组件必须在所选课件数表的数值范围内，最多一个1000，并且必须还原为S。

### 文字体系与1000边界

网站默认拉丁字母输入、希伯来字母输出；阿拉伯字母保留为可选项。阿拉伯课件大数表包含1000对应的字母 `غ`，因此能完整表示原示例的千位组件。阿拉伯结果保持同一文字体系，后缀为 `ال` 或 `ايل`；辅助读法标为字母名，不把希伯来固定拼读表直接套用到阿拉伯文字。

希伯来输出使用课件的扩展大数表，500—900对应五种词尾字形；课件1000栏没有希伯来对应字母。拆分出现1000时，网站会提示改用阿拉伯输出或人工提供有效拆分，不自行造字，也不混写两种文字。希伯来后缀分别为 `אל`、`איל`。

出处：原讲义第3—4页；当前PPT第55页及演讲备注。输入整理、连续权重、11—19处理和通用百/十/千拆分，是网站明确标注、允许人工复核的实现约定。
